# AntiESP-att

A server-side anti-ESP mod for A Township Tale that prevents clients from detecting entities hidden behind walls and other solid geometry.

Unlike traditional visual hiding methods, ServerAntiESP filters entity replication at the networking level, ensuring occluded entities and their data are not accessible in the client's Unity object hierarchy.

Features include server-side line-of-sight detection, per-player entity visibility, dynamic spawning and despawning, and protection against conventional ESP and wallhack modifications.
